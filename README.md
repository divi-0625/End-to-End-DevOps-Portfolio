# End-to-End DevOps Portfolio

![Portfolio Preview](images/portfolio.png) 

## Portfolio Preview

A personal portfolio website showcasing my DevOps learning journey, projects, and technical skills. This project is built as part of my hands-on DevOps learning and is continuously enhanced as I learn new tools, technologies, and deployment practices.

---

## Features

* Responsive single-page portfolio
* Modern UI built with HTML, CSS, and JavaScript
* Project showcase
* DevOps learning timeline
* Downloadable resume
* Contact section *(currently UI only)*
* Automated deployment using GitHub Actions
* Hosted on GitHub Pages
* Containerized using Docker and Nginx
* Deployed on Kubernetes using Minikube
